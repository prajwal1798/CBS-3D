# Code of Conduct

## Standard

CBS3D++ contributors must communicate professionally and evaluate work on technical evidence. Harassment, discrimination, personal attacks, intimidation and deliberate disruption are not acceptable.

## Expected behaviour

- Critique code, equations and evidence rather than individuals.
- State uncertainty and limitations explicitly.
- Provide reproducible technical information.
- Respect authorship, copyright, licences and data restrictions.
- Keep private credentials, cluster identifiers and unpublished research data confidential.
- Acknowledge prior numerical and software contributions accurately.
- Accept correction when a claim is not supported by validation.

## Unacceptable behaviour

- Harassment or discriminatory language.
- Publishing private information without permission.
- Misrepresenting validation, performance or authorship.
- Uploading restricted legacy source or third-party data without rights.
- Sabotaging issues, pull requests, builds or benchmark records.
- Repeatedly ignoring maintainer instructions intended to protect numerical correctness or repository security.

## Scientific-integrity requirement

Results must not be selected, altered or presented to conceal failed convergence, conservation errors, mesh sensitivity or parallel inconsistency. Performance claims must identify the measured region, hardware, configuration and baseline.

## Enforcement

Report conduct concerns privately to the repository owner. Maintainers may edit or remove comments, close contributions, restrict participation or report serious platform violations.

Enforcement decisions should be proportionate, documented where appropriate and separated from technical disagreement.
